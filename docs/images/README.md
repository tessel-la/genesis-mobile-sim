# Preview provenance

`warehouse.png` is an actual Genesis CPU render of the scene built by
[`environment.py`](../../src/genesis_mobile_sim/environment.py). The camera is placed
in the warehouse aisle; no robot model or meshes are loaded for this capture. Room
geometry and layout belong to this MIT-licensed integration. Shelves, pallet jacks,
and clutter come from the pinned AWS RoboMaker assets; their [source](../../assets/environments/warehouse/SOURCE.md)
and [permission notice](../../assets/environments/warehouse/LICENSE) remain available.
The image does not show navigation results or establish simulation performance.

`control-panel.png` is a screenshot of the MIT-licensed companion
[Go2 Control panel](https://github.com/tessel-la/robo-boy-go2-control-panel), release
`v1.3.0`, with sample telemetry. Its source license is preserved in
[`CONTROL-PANEL-LICENSE`](CONTROL-PANEL-LICENSE).

These are documentation previews. They contain no Unitree robot meshes, external
photographs, personal information, or claim of endorsement by an upstream organization.

The panel's runtime theme comes from [Robo-Boy](https://github.com/tessel-la/robo-boy),
licensed under Apache-2.0. Its license is preserved in
[`ROBOBOY-LICENSE`](ROBOBOY-LICENSE).
